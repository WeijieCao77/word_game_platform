# VAL MANAGER 全量机制扫描 · 平台能力对照

以旗舰作品 VAL MANAGER 为标尺，逐个系统核对「字游」平台能不能 1:1 复刻。
这是平台的**初期标的**：复刻不出来的每一条，就是平台要补的功能。

- 原作规模：`src/engine` 7,010 行 + `src/ui` 6,122 行 = **13,132 行**；
  世界数据 78 支战队 / 518 名选手（`src/data/world.json`，370KB）
- 扫描时间：2026-08-25，commit `0ccd74b`

图例：✅ 现在就能做　🟡 能做但要绕　❌ 平台缺这个能力

## 结论

**能 1:1 复刻的**：经理养成与加点、合同与求职、训练与状态、转会报价与谈判、
商业与赞助、教练招聘、球员信任、赛事积分与奖金、事件系统、归因面板。
本次实测：`templates/vct-manager.json` 三级校验零错误零警告，
600 局模拟全结局可达、开局即死 0。

**平台还缺 8 项**，按「补上之后能解锁多少东西」排序：

| # | 缺的能力 | 除了这款还惠及谁 |
| --- | --- | --- |
| 1 | **关系网（pair state）** | 恋爱、宗门、宫斗、群像——所有「谁和谁」的玩法 |
| 2 | **淘汰赛对阵表（bracket）** | 一切赛事题材：体育、武道会、选秀、辩论赛 |
| 3 | **分步可介入结算**（逐回合、中途换策略） | 战斗、庭审、谈判、直播带货——所有「过程本身是内容」的场面 |
| 4 | **世界自主演化**（你不参与时对手也在变） | 所有经营/模拟：市场、对手、NPC 命运 |
| 5 | **生涯迁移**（换东家继续，状态部分继承） | 一切「一章结束但人生继续」：转学、改朝换代、二周目 |
| 6 | **赛段（stage）**：赛季内的第三级时间 | 学期/赛程/剧幕结构 |
| 7 | **日程占用**（这件事占掉某几天） | 时间管理类玩法 |
| 8 | **周计划锁定**（定了就得执行完） | 「决策有承诺成本」的设计 |

前三项做完，平台就能覆盖 VAL MANAGER 九成以上的玩法密度。
