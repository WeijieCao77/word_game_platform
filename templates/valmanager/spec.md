# 复刻 VAL MANAGER —— 给平台 AI 的建造说明书

我要你用这个工作台，做出一款**玩起来和《VAL MANAGER》一模一样**的电竞经理游戏。

**「一模一样」指的是玩家的体验，不是代码。** 玩家看不到代码，他看到的是：
每天要做几件事、比赛能不能一回合一回合看着打、选手会不会因为坐板凳而不信任你、
一个赛季有多长、界面上有多少东西可以点。这些必须和原作一样。

**题材名字可以是我们自己的**——联盟、战队、选手叫什么都行，不必是 Valorant。
但**系统的深度和界面的丰富度一分都不能少**：原作 13,132 行代码、26 个界面、
78 支战队 518 名选手，那个体量就是体验的一部分。

**要避免的失败长什么样**：之前用平台做过两款「电竞经理」，共享的只有题材词——
都叫电竞经理、都有选手和赛季，但玩家坐下来玩的是两个完全不同的东西：
原作按天推进、有 ban/pick、有逐回合直播、有 26 个专属界面；那两款是每周点三下、
一次结算给个比分、所有游戏长一个样。**这次不能再是那样。**

作品是自由模式：界面、玩法结构全部由你写的 HTML/CSS/JS 决定。
平台的运行库（wgp.js / wgp.css）已经垫在下面——界面切换、表格、进度条、弹层、
可复现随机数、存档都直接用它，不要自己重写这些轮子。

## 一点五、开局：先捏一个经理，再挑东家（**玩家看到的第一屏**）

原作不是「点开就进游戏」。玩家先花两分钟把**自己**捏出来——这是整局的第一印象，
少了它，体验从第一秒就对不上。四步：

### 1. 名字与年龄（18–60）
年龄是**这一屏唯一真正的取舍**：岁数换声望，声望换一份更好的第一工作，代价是成长变慢。

| 档 | 年龄 | 说明 | 成长倍率 |
| --- | --- | --- | --- |
| 青年 | ≤26 | 没人认识你，只能从底层带起，但成长最快 | 1.45× |
| 中生代 | 27–35 | 有一定履历，能接手中游球队 | 1.0× |
| 资深 | ≥36 | 名字有分量，能接手强队，但你基本定型了 | 0.6× |

初始声望按年龄算：≤26 岁 `35 + (年龄-18)×1.1`；27–35 岁 `46 + (年龄-27)×1.6`；
≥36 岁 `61 + (年龄-36)×0.9` 封顶 72。再加上出身的声望修正，最后夹在 25–84。
（战队的声望也是同一把尺子，49–83，所以两边能直接比。）

### 2. 出身：从八个里**随机发三个**给玩家挑（本局固定）
设计上「出身主要是个故事，不是一套 build」——**每个出身都是两个强项 + 一个同等幅度的弱项**，
没有哪个严格更好，差别只在你拿到哪几根杠杆。

| 出身 | 声望 | 强 / 弱 | 一句话 |
| --- | --- | --- | --- |
| 退役职业选手 | +12 | 更衣室·战术 / 商务 | 你在赛场上待过，选手信你说的话，但从没管过账。 |
| 前教练·助教 | +9 | 战术·训练 / 谈判 | 你在教练席上熬了很多年，只是不擅长跟人谈钱。 |
| 数据分析师 | −2 | 眼光·训练 / 更衣室 | 你靠一份份报告看人，比谁都准，但很少走进更衣室。 |
| 别的项目转来 | +8 | 商务·谈判 / 战术 | 你在另一个项目做到过顶级，只是这个游戏还得重新学。 |
| 青训教练 | −4 | 带新人·眼光 / 战术 | 你带出过好几个新人，但没打过真正的大场面。 |
| 主播·名人 | +4 | 商务·谈判 / 更衣室 | 你有流量，赞助商喜欢你，但圈子里没人把你当行家。 |
| 投资人 | +6 | 商务·体能 / 战术（**开局多 90 万资金**） | 你自己掏钱进的圈，更懂生意而不是比赛。 |
| 草根出身 | −8 | 训练·带新人 / 商务 | 你从网吧战队一路打杂上来，只是没人听过你的名字。 |

### 3. 天赋加点：八项能力，**8 点，每点 +5**
八项：**训练 / 谈判 / 战术 / 眼光 / 体能 / 商务 / 更衣室 / 带新人**。
基础全 50，出身的两个强项 65、弱项 35；上限 90，退点不能低于出身给的底。

八点**故意不够把每项都点满**：要么两项点到顶，要么摊平但样样平庸。
出身决定你从哪儿起步，这八点决定你成为什么样的经理。每一项都要有一句人话说明它管什么：

| 天赋 | 管什么 |
| --- | --- |
| 训练 | 训练收益更高 |
| 谈判 | 转会与续约更容易谈成 |
| 战术 | 比赛中的战术加成更大 |
| **眼光** | **看得准潜力——低的时候选手潜力只显示成一个区间，高了才显示确切数字** |
| 体能 | 伤病更少，休息恢复更多体能 |
| 商务 | 赞助收入更高 |
| 更衣室 | 士气更稳，不满消退更快 |
| 带新人 | 23 岁以下选手的训练收益更高 |

「眼光」那条尤其要做：**经理自己的能力改变界面上能看到什么**，
这是原作最讲究的一处设计，也是玩家第二局会想换个练法的理由。

### 4. 挑东家：够不着的门进不去
按赛区（Americas / EMEA / Pacific / China）分栏，每区分 VCT 与 Challengers 两档，
按首发五人的平均综合排序，每支队要显示队标、强度、预算。

**你的声望不够就选不了那支队**，而且——**每个赛区最强的三支队开局一律锁死**，
声望再高也不给。第一份工作就该是要往上爬的。

## 二、时间：按天推进，一年 336 天，八个赛段

玩家选一支队当经理。**这个游戏没有结局**——被解雇叫「任期结束」，可以去应聘别的
俱乐部继续，年份一直往前走。不要给它设计结局。

| 赛段 | 天 |
| --- | --- |
| 季前准备 | 0–20 |
| Kickoff | 21–62 |
| Masters I | 63–88 |
| Stage 1 | 89–168 |
| Masters II | 169–194 |
| Stage 2 | 195–274 |
| Champions | 275–310 |
| 休赛期 | 311–335 |

**推进节奏**：下一场正式比赛在 7 天以后，就按周推进（一回合 = 一周）；否则一回合 = 一天。
赛季中一回合 2 个行动点，按周推进时 4 个。

**转会窗**：第 0–20 天（季前）、169–194 天（Masters II 期间的短窗）、311–335 天（休赛期）。
窗口关着时不能报价。

## 三、一天做什么：行动点只花在「对外的事」上

要花行动点的 11 类事务，每一类都该有自己的界面或弹层：
提交报价 / 答复报价 / 挂牌撤牌 / 解约 / 安排商务活动 / 拜访赞助商 /
筹备俱乐部活动 / 直播合同 / 约训练赛 / 教练组（挖人、签约）/ 设施升级。

**排首发和调战术不花行动点**——经理不该为了省一次跑腿而派一套更差的阵容。

## 四、比赛：过程本身就是内容

- BO1 / BO3 / BO5。13 张地图：Ascent, Bind, Breeze, Corrode, Fracture, Haven,
  Icebox, Lotus, Pearl, Split, Summit, Sunset, Abyss
- **地图 ban/pick**：BO1 = ban ban ban ban ban ban；BO3 = ban ban pick pick ban ban；
  BO5 = ban ban pick pick pick pick。ban 的逻辑是「对面最喜欢、我方最不喜欢的那张」，
  每一步都要有一行记录（「XX ban 掉 Haven」）
- **逐回合模拟**：一张图先到 13 回合，10:10 进加时。每一回合要**跑给玩家看**
  （一回合几百毫秒），不是直接甩比分。回合条带把每一回合画成一格，谁赢一眼看得出
- **战术暂停**：每方每张图 2 次，加时各 +1。暂停时玩家能改战术指令，效果几回合后衰减
- **跳过**：玩家可以不看，同一套模拟直接跑完，结果完全一致
- **优势拆解**：这一局的优势来自哪里——个人能力 / 战术 / 教练组 / 地图适配 /
  队内和谐 / 状态，逐项列出来，别只给结果
- 分路影响击杀分布：决斗者 1.18、自由人 1.03、先锋 0.98、哨卫 0.95、控场 0.90
- 赛后每人记 10 项赛季统计：场次、回合、击杀、死亡、助攻、首杀、首死、伤害、残局、MVP

## 五、其余系统（每一个都要做）

**训练**：每人每周一个专项 + 全队集训 + **双人搭档**；**计划确认后锁定一周**，
中途改要付一周代价。教练三维与设施等级放大收益。

**转会**：多维报价评分——价钱、角色承诺、出场时间、球队实力、球员意愿；球员会拒绝；
**AI 战队之间自己也在转会**；别的队会来买你的人，你要答复。挂牌、解约、续约、合同条款。

**商务**：商务活动、拜访赞助商、俱乐部活动、直播合同。代价永远是同一种货币——
上商务的那天，队伍就没在训练。

**教练组与设施**：主教练 / 助教 / 分析师三档，分析师 5 种专精；可以去**挖别队的教练**；
设施升级要花钱。

**关系（三条独立的轴，不要合并成一个「团队默契」）**：
- `morale` 士气：这一周的情绪，被结果推着走，波动大
- `grievance` 怨气：一条具体的抱怨——你答应我的位置没给我
- `trust` 信任：对经理的慢结论，由你做过的一切累积；坐板凳会掉，队友被卖会连带
- `bonds` 羁绊：两两之间的关系，一起打上来的会互相掩护，carry 的会烦总是送的

**生活事件**：伤病、退役、更衣室矛盾——你不去找它也会发生。

**生涯**：俱乐部给年度目标，达不到有下课风险；被解雇后可以主动**应聘**别的俱乐部，
够不着的门会礼貌拒绝，状态部分继承。年份一直往前。

**财务**：周薪账单、奖金、赞助收入、设施投入，每周结算。

那是被骗了一次：他不知道你有几轮，他只知道这游戏是半成品还装成完整的。
**宁可导航上只有三个页签而三个都是真的，也不要十一个页签里八个是空壳。**
做完一个加一个。

## 七、怎么一步步搭（每一轮都要交付一个能跑的东西）

一轮对话有时间上限，超了平台会把你手上的东西存好、把话交代给创作者，下一轮接着来。
所以**不要试图一轮写完**，按下面的顺序一层层长：

1. **开局流程 + 骨架**。开局就是第一节半那四步：名字年龄 → 随机发三个出身 →
   8 点天赋加点 → 挑东家（声望不够的队进不去，每赛区最强三队一律锁死）。
   **这一步必须先做**——它是玩家看到的第一屏，少了它体验完全对不上。
   同一轮把骨架也搭上：读三张表，顶部导航（11 个界面按组分栏）与总览页，
   显示我的战队、日期、赛段、行动点。
   这一轮结束就该能：捏一个经理 → 挑一支队 → 进到总览页
2. 阵容页：我的首发五人 + 替补，可排序表格，点一行开选手详情（八维 + 特点 + 合同）
3. 赛程与积分榜：按 336 天的日历排赛程，积分榜按联赛分组
4. 比赛：ban/pick → 逐回合模拟 → 回合条带 → 战术暂停 → 优势拆解
5. 训练：专项 + 集训 + 搭档 + 一周锁定
6. 转会：报价评分、挂牌、解约、AI 队之间的转会
7. 商务 + 财务 + 教练组 + 设施
8. 关系三轴 + 羁绊 + 生活事件
9. 生涯：年度目标、下课、应聘下一家、跨赛季继承
10. 打磨：存档、教程、每日简报、手机适配

文件大了 read_file 会给你目录（每一节在第几行），照着目录取那一段就行——
文件再大都改得动，不要因为看不到全文就重写。
